## 대표 경험

### 프로시저 중심의 업무 로직을 Java로 이관

**센드페이 · 운영 개선**<br />
현재 서비스와 무관한 게임 전용 로직을 제거하고 프로시저를 단계적으로 이관했습니다. 정산 데이터로 결과를 검증하고, 오류 시 저장 취소·실패 응답과 로그 분석이 가능하도록 개선했습니다.

### 데이터 이관부터 관리자 업무 자동화까지

**한빛글로벌 · 서버·DB·서비스 개발**<br />
재구축에서 Docker 서버·DB 설계와 회원·거래·잔액 이관을 맡았습니다. 기존 데이터와 이관 결과를 대조하고, 이후 조합원 관리·포인트 지급 서비스를 직접 구축했습니다.

### 담당자의 업무에 맞춘 쇼핑몰 개선과 업종 전환

**퍼니줌 → 키즈마켓 · 관리자 기능과 서비스 전환**<br />
외주 쇼핑몰 소스를 인수하고 운영·정산 담당자와 필요한 기능을 정리했습니다. 상품 등록 항목과 공통 카테고리를 다듬고, 후속 프로젝트에서는 같은 기반을 유아동복 서비스로 전환했습니다.

### AI의 문서·구현·테스트 결과를 검토하고 반복 개선

**최근 개인 개발 · Codex 활용**<br />
요구사항과 작업 기준을 먼저 문서화하고 검토한 뒤 구현·테스트를 진행합니다. 오류가 문서의 정의 문제인지 코드 문제인지 구분해 수정을 요청하고, 반복 오류는 AGENTS.md에 반영합니다. 실행·테스트 결과와 미검증 범위를 구분해 출시 여부를 판단합니다.
